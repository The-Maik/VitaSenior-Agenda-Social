# 🌿 VitaSênior - Agenda Social

Atividades, encontros e novas conexões para a terceira idade. Consulte a agenda e cuide das suas inscrições pelo celular.

## Sobre o VitaSênior

O VitaSênior aproxima pessoas idosas de atividades educativas e de convivência. Participantes usam o aplicativo Android para se inscrever; organizadores administram os encontros e acompanham as vagas pela Web.

## Funcionalidades

- 📅 Agenda com data, horário, local e vagas disponíveis
- ✅ Inscrição, consulta, alteração do nome e cancelamento pelo aplicativo
- 🔐 Código individual para acessar cada inscrição
- 🗂️ Painel Web para cadastrar, editar e excluir atividades
- 📚 Biblioteca educativa com busca, texto ampliado e alto contraste

## Como usar

1. [Baixe o aplicativo Android](https://github.com/The-Maik/VitaSenior-Agenda-Social/releases/download/v1.0.0/vitasenior.apk).
2. Escolha uma atividade e informe seu nome ou apelido.
3. Guarde o código recebido para consultar, alterar ou cancelar sua inscrição.
